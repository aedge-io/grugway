  by [@raphael-paier](https://github.com/raphael-paier))

#### Trimming down

In an effort to actually simplify grugway, I've concluded that the initial
adapters module has to be removed. It was moved to the `examples` directory to
show how lifting fallible functions composes with custom `Result` constructors
for finer grained control.

Also `trip` and `rise` methods have finally been removed, after they've been
already deprecated in `eitherway` a while back.

### Features

- feat(async): implement Promise parity without subclassing
  ([7adbbd1](https://github.com/aedge-io/grugway/commit/7adbbd110eeb860c0e5b6be4f9795ee6515c1161
  by [@raphael-paier](https://github.com/raphael-paier))

#### Light weight `Task`

I've finally came around to implement a change, I've had already planned for
`eitherway` as well: Namely providing full `Promise` compatibility without the
heavy hits of subclassing.

This is fully backwards compatible and `instanceof` checks still work, thanks to
static initialization blocks.
