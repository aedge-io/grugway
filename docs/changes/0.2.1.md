#### Maintenance

While not adding any new functionality, this release brings test coverage close
to 100%, improves docs and... finally got rid of namespaces!

Although it may seem rather trivial, retaining the ergonomics afforded by
namespace declaration merging while keeping the whole library API intact was a
tad trickier than anticipated. A nice consequence is that it removes a
typescript-only construct from the transpiled bundle, thus reducing it's size
and boosting load times (a bit).
